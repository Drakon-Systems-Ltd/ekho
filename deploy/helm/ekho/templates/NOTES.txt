Ekho has been installed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

A single relay pod is running (SQLite requires a single writer — see the
chart README for why replicaCount must stay at 1).

1. Check pod status:

   kubectl --namespace {{ .Release.Namespace }} get pods -l "app.kubernetes.io/instance={{ .Release.Name }}"

2. Access the operator console:

{{- if .Values.ingress.enabled }}

   Ingress is enabled. Browse to:
   {{- range $host := .Values.ingress.hosts }}
     {{- range .paths }}
   http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}{{ .path }}ui/
     {{- end }}
   {{- end }}

{{- else if contains "NodePort" .Values.service.type }}

   export NODE_PORT=$(kubectl --namespace {{ .Release.Namespace }} get svc {{ include "ekho.fullname" . }} -o jsonpath="{.spec.ports[0].nodePort}")
   export NODE_IP=$(kubectl --namespace {{ .Release.Namespace }} get nodes -o jsonpath="{.items[0].status.addresses[0].address}")
   echo "Open http://$NODE_IP:$NODE_PORT/ui/"

{{- else if contains "LoadBalancer" .Values.service.type }}

   NOTE: It may take a few minutes for the LoadBalancer IP to be available.
   export SERVICE_IP=$(kubectl --namespace {{ .Release.Namespace }} get svc -w {{ include "ekho.fullname" . }} --template "{{"{{"}} range (index .status.loadBalancer.ingress 0) {{"}}"}}{{"{{"}}.{{"}}"}}{{"{{"}} end {{"}}"}}")
   echo "Open http://$SERVICE_IP:{{ .Values.service.port }}/ui/"

{{- else }}

   kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "ekho.fullname" . }} 4000:{{ .Values.service.port }}
   # Then browse to:
   #   http://localhost:4000/ui/

{{- end }}

3. Create your first operator. Inside the relay pod run:

   kubectl --namespace {{ .Release.Namespace }} exec -it {{ include "ekho.fullname" . }}-0 -- \
     tsx packages/relay/src/setup.ts

   (Or run the setup script: npm run setup)

4. Log in at /ui/ and enrol your first agent.

{{- if not .Values.persistence.enabled }}

WARNING: persistence.enabled=false — the SQLite DB is stored in an emptyDir
and will be LOST on pod restart. Set persistence.enabled=true for anything
beyond dev/testing.
{{- end }}

{{- if eq .Values.secrets.operatorSessionSecret "change-me" }}

WARNING: operatorSessionSecret is the default. Rotate it now:
   helm upgrade {{ .Release.Name }} <chart> --set secrets.operatorSessionSecret=$(openssl rand -hex 32) --reuse-values
{{- end }}
